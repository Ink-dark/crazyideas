# HandleTokens
功能：
1. 本地化AI调用（只允许内网地址进行API调用，由HandleTokens处理对接模型提供商，从源头杜绝真实API Key泄露至互联网）
2. 可视化API key 权限管理（用户可以可视化管理自己的API Key，包括创建、删除、修改权限等操作）
 1) 速率/并发限制
 2) 有限次数/使用金额限制
 3) 时间限制（到时过期）
 4) 模型调用限制（令牌限制模型使用权限）
3. 安全审计与经济
 1) 模型使用计数（Tokens）
 2) 模型预扣费（余额估计，用于开放平台对账）
 3) 模型调用记录（包括调用时间、调用次数、调用金额等）
 4) 余额自动查询
4. Tauri 控制台（考虑中）
5. Web 控制台（考虑中）
6. 模型杂交（考虑中）
7. 模型输入输出回溯
8. 接口协议互转（OpenAI协议、Anthopic协议）
9. 目标：真实的key永远只放在HandleTokens，前台接入永远只接入HandleTokens所产生的内网key，调用永远路由到HandleTokens，即便泄露，资产无虞。。
适合于搞开源项目的小白、技术公司或组织，防止忘记gitignore和git误操作导致的真实key泄露。

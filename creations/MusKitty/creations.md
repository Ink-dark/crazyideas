# MusKitty

下一代 AI 浏览器核心 — 让您的 AI 小伙伴，在您掌控下，智能浏览网页。

MusKitty 是 AI 驱动浏览器 **MusCat（口罩猫）** 的智能核心。她不是简单的自动化脚本，而是一个在用户全程监督与授权下，能够像真人一样理解页面、操作交互的智能伙伴。

## 核心理念：赋能，而非取代

AI 应该作为人类能力的延伸，在完全透明和可控的前提下工作。MusKitty 的每一次点击、每一次输入、每一次导航，都会明确征得用户同意。

## 核心特性

- 拟人化操作 — 超越简单 API 调用，能识别页面元素，像真人一样思考操作逻辑（点击、滚动、填写表单、切换标签页）
- 用户主权 — 所有关键操作步骤均会暂停，清晰说明动作意图，等待明确许可（批准或跳过）
- 自然语言任务 — 直接用自然语言描述目标，如"找到本月最热门的 AI 新闻摘要"
- 强大的上下文理解 — 结合页面 DOM、视觉布局和文本内容，精准理解当前页面状态
- 模块化与可扩展 — 核心引擎与任务技能分离，可轻松训练或添加新的技能包

## 安全与控制

1. 权限沙箱 — 精确授权特定网站或域名范围
2. 操作确认 — 每一步清晰可见，可随时中断
3. 无后台隐藏行为 — 所有活动在浏览器前台有明确日志和状态
4. 本地处理优先 — 敏感信息处理尽可能在本地进行

## 关于名字

- **MusCat**（口罩猫）— 主浏览器，在纷繁网络世界中提供智能过滤与保护
- **MusKitty** — 藏在里面的核心，聪明伶俐、执行具体任务的小猫，永远听从召唤

## 技术方向

AI Agent + 浏览器自动化 + DOM理解 + 视觉布局分析 + 模块化技能系统

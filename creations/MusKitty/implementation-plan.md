# 实现计划

## 当前状态

项目处于早期规划阶段，已完成概念设计和核心架构定义。

## 技术选型（待定）

| 领域 | 候选方案 | 考量 |
|------|----------|------|
| 浏览器协议 | CDP (Chrome DevTools Protocol) | 主流，功能最全 |
| 页面感知 | DOM Parser + Vision Model | 多模态理解 |
| 任务规划 | LLM + 结构化任务模板 | 灵活性与可控性平衡 |
| 技能系统 | WASM / JS Plugin | 跨语言、安全沙箱 |
| 安全沙箱 | 进程隔离 / 权限令牌 | 最小权限原则 |

## 开发路线

### Phase 1 — 核心原型

- MusCat 浏览器壳基础框架
- CDP 协议通信层
- 基础 DOM 解析与元素识别
- 简单点击/输入操作的执行与确认流程
- 最小可用的操作确认面板 UI

### Phase 2 — 感知与规划

- 页面视觉布局分析
- 自然语言任务解析（NL → 结构化任务）
- 任务执行计划生成器
- 多步操作的状态机调度
- 上下文短期记忆

### Phase 3 — 技能系统

- 技能包格式定义
- 技能加载器与注册表
- 内置技能：表单填写、搜索聚合
- 技能的热加载与卸载
- 技能市场（社区技能发现）

### Phase 4 — 安全与控制

- 域名/操作级权限沙箱
- 操作确认流程 UI 与后端
- 全量操作审计日志
- 隐私保护（数据本地化、敏感信息脱敏）
- 信任网站免确认设置

### Phase 5 — 进阶功能

- 复杂多页流程任务（如"完成整个购物流程"）
- 视觉对比与验证（确认操作结果是否符合预期）
- 长期记忆与用户偏好学习
- 错误恢复与自动重试
- 跨会话任务恢复

### Phase 6 — 生态与发布

- 技能开发 SDK 与文档
- 技能市场/社区上线
- 跨平台支持（Windows / macOS / Linux）
- 浏览器扩展版（轻量版）
- 多语言自然语言支持

## 里程碑

- v0.1.0 — 原型：基础浏览器 + 单步操作 + 确认面板
- v0.2.0 — 感知：DOM + 视觉分析 + 自然语言任务解析
- v0.3.0 — 技能：技能系统就绪 + 内置技能集
- v0.4.0 — 安全：完整沙箱 + 审计 + 隐私保护
- v1.0.0 — 正式版：全功能 + 技能市场 + 跨平台

# 核心概念

## 拟人化操作

MusKitty 的核心差异在于不使用简单的 API 调用或固定脚本，而是模拟真人的浏览行为：

### DOM 感知

解析页面 DOM 树，识别所有可交互元素（按钮、链接、输入框、下拉菜单），理解元素的语义角色和当前状态。

### 视觉理解

不只看代码结构，还能理解视觉布局：
- 元素是否在可视区域？
- 是否被其他元素遮挡？
- 视觉层次和优先级？

### 操作推理

结合 DOM 和视觉信息进行拟人化推理：
- "这个按钮是蓝色的主要操作按钮" → 点击
- "这个表单有多步，当前在第 2 步" → 填写当前步骤后点击"下一步"
- "页面正在加载中" → 等待加载完成再继续

## 任务模型

### 自然语言 → 结构化任务

```
用户输入: "帮我找到性价比最高的游戏鼠标并加入购物车"

解析结果:
├── 意图: 商品搜索 + 筛选 + 加入购物车
├── 目标商品: 游戏鼠标
├── 筛选条件: 性价比最高
├── 最终动作: 加入购物车
└── 子任务:
    ├── 1. 打开电商平台搜索"游戏鼠标"
    ├── 2. 按销量排序，收集前10个商品
    ├── 3. 提取每个商品的价格、评分、评论数
    ├── 4. 计算性价比得分
    ├── 5. 确认最优选项并向用户展示
    └── 6. 用户确认后，点击"加入购物车"
```

### 任务执行状态机

```
IDLE → PARSING → PLANNING → CONFIRMING → EXECUTING → SUMMARIZING → IDLE
  ↑        ↓          ↓           ↓            ↓            ↓
  └────────┴──────────┴───────────┴────────────┴────────────┘
                    任意状态可跳转到 IDLE（中断/取消）
```

## 技能系统

### 技能定义

技能是一个独立的、可复用的任务处理单元：

```yaml
skill:
  name: "电商比价"
  version: "1.0.0"
  domains: ["*.taobao.com", "*.jd.com", "*.pinduoduo.com"]
  actions:
    - search_product
    - extract_price
    - add_to_cart
  confirm_policy: "per_action"  # per_action | per_domain | always
```

### 技能加载

```
技能注册表 (registry)
  ├── 内置技能（builtin/）— 随引擎发布
  └── 社区技能（community/）— 用户安装后加载
```

### 技能生命周期

1. 注册 — 声明技能描述、适用域名、支持的操作
2. 匹配 — 根据用户任务自动匹配合适的技能
3. 激活 — 加载技能到当前会话
4. 执行 — 在安全沙箱内运行
5. 卸载 — 任务完成后释放资源

## 安全模型

### 三层授权

| 层级 | 粒度 | 示例 |
|------|------|------|
| 域名授权 | 网站级别 | "允许访问 taobao.com" |
| 操作授权 | 动作级别 | "允许填写表单"、"禁止提交订单" |
| 步骤确认 | 单步级别 | "确认点击'立即购买'按钮？" |

### 操作分类与授权策略

- **只读操作**（浏览、查看、搜索）— 默认允许，首次提示
- **输入操作**（填写文本、选择选项）— 需要域名级授权
- **提交操作**（点击提交、确认订单）— 必须逐次确认
- **金融操作**（支付、转账）— 严格禁止，需用户亲自完成

### 隐私保护

- 敏感数据（密码、支付信息）不经过 AI 模型
- 页面截图和 DOM 数据默认本地处理
- 用户可随时清除所有浏览记录和操作日志

## 上下文记忆

### 短期记忆

会话级别的上下文，包括：
- 当前任务的目标和进度
- 最近的操作历史
- 当前页面状态快照

### 长期记忆

跨会话的持久化偏好：
- 常用网站的授权设置
- 用户的操作偏好（如"总是按销量排序"）
- 技能使用频率和效果评分

## 浏览器通信

MusKitty 通过标准浏览器自动化协议与 MusCat 通信：

- **CDP (Chrome DevTools Protocol)** — 主协议，支持 DOM 操作、网络监听、性能分析
- **WebDriver** — 备用协议，跨浏览器兼容
- **页面注入脚本** — 轻量级的页面内辅助脚本，用于元素高亮、状态提示等 UI 反馈

# 五子棋全平台版 -- 开发者实操手册

> 本文档为开发者实操指南，包含技术选型决策、环境搭建步骤、分阶段开发任务清单。
> AI 对手基于 LLM 大语言模型，支持 OpenAI / Anthropic / Ollama 多后端切换。
> 整体架构基于 **Rust 核心库 + Tauri 2.0 + Cloudflare Serverless**，实现 Web / 桌面 / 移动三端统一。

---

## 一、架构设计理念

### 1.1 核心架构

- **Rust 核心库**（gomoku-core）：游戏逻辑、棋盘状态、胜负判定、LLM 调用封装——所有平台共用
- **Web 端**：React 前端 + Cloudflare Workers（Rust 编译为 Wasm）后端
- **桌面端**：Tauri 2.0（Rust 后端 + WebView 前端），支持 Windows / macOS / Linux
- **移动端**：Tauri 2.0（Rust 后端 + WebView 前端），支持 iOS / Android
- **三端共用**：同一套 Cloudflare 后端服务（在线联机、用户系统、LLM API）

### 1.2 项目架构图

```
┌─────────────────────────────────────────────────────────┐
│                    共享 React 前端                        │
│              (Web / 桌面 WebView / 移动 WebView)          │
├─────────────┬──────────────────┬────────────────────────┤
│  Cloudflare │   Tauri 桌面端    │    Tauri 移动端         │
│   Pages     │  (Win/Mac/Linux) │   (iOS/Android)        │
├─────────────┴──────────────────┴────────────────────────┤
│              Rust 核心库 (gomoku-core)                    │
│         board / rules / ai / serde_types / protocol      │
├────────────────────────┬────────────────────────────────┤
│   Cloudflare Workers   │      Tauri Rust 后端            │
│   (在线服务)            │      (本地服务)                  │
│   D1 / KV / R2 / DO    │      本地 SQLite / 文件系统     │
├────────────────────────┴────────────────────────────────┤
│                    LLM 层                                │
│         OpenAI / Anthropic / Ollama                      │
└─────────────────────────────────────────────────────────┘
```

#### 2.4.1 LLM 多后端架构

采用 **适配器模式（Adapter Pattern）**，定义统一 trait `LLMService`，各后端实现各自适配器：

```
┌─────────────────────────────────────────┐
│           LLM Service Layer             │
│  (统一 trait: get_move(board) -> Move)  │
├─────────┬──────────┬───────────────────┤
│ OpenAI  │ Anthropic│     Ollama        │
│ Adapter │ Adapter  │    Adapter        │
├─────────┴──────────┴───────────────────┤
│         OpenAI-Compatible API          │
│    (GPT-4o / DeepSeek / 通义千问...)    │
└─────────────────────────────────────────┘
```

#### 2.4.2 三种后端对比

| 维度 | OpenAI 兼容接口 | Anthropic Claude | Ollama 本地部署 |
|------|----------------|-----------------|----------------|
| 代表模型 | GPT-4o, GPT-4o-mini, DeepSeek-V3 | Claude 3.5 Sonnet | Qwen2.5, DeepSeek-R1 |
| 部署方式 | 云端 API | 云端 API | 本地 GPU / CPU |
| 成本 | 按 Token 计费 | 按 Token 计费 | 硬件成本 + 电费 |
| 延迟 | 1-5 秒 | 1-5 秒 | 2-15 秒（取决于硬件） |

#### 2.4.3 LLM Prompt 设计

系统 Prompt 示例：

```
你是一个五子棋 AI 对手。你将收到当前棋盘状态，需要返回你的落子位置。

棋盘规则：
- 15x15 的标准五子棋棋盘
- 先连成五子的一方获胜
- 0 表示空位，1 表示黑棋（先手），2 表示白棋（后手）

请以 JSON 格式返回你的落子：
{
  "row": 0-14 的整数，表示行号，
  "col": 0-14 的整数，表示列号，
  "message": "可选，你想对对手说的话"
}

注意：
1. 必须选择一个空位落子（值为 0 的位置）
2. row 和 col 必须在 0-14 范围内
3. 尽量选择对自己有利的策略位置
4. message 字段可以是对对手的鼓励、感叹或策略评论
```

| 组件 | 方案 | 说明 |
|------|------|------|

| 缓存 | **Cloudflare KV** | Workers 原生绑定 |
| 文件存储 | **Cloudflare R2** | 头像、棋谱文件 |
| WebSocket | **Durable Objects** | 有状态 WebSocket |
| LLM | API 调用或本地部署 | OpenAI / Anthropic / Ollama |

### 2.6 架构优势

- **Rust 核心库复用**：游戏逻辑、AI 调用等核心代码三端共用，零重复开发
- **全平台覆盖**：一套 React 代码 + Tauri 2.0，同时覆盖 Web / 桌面 / 移动
- **零服务器运维**：在线服务基于 Cloudflare Workers，无需管理服务器
- **全球低延迟**：Workers 在 300+ 城市边缘节点运行
- **本地优先**：Tauri 端可直接调用 Rust 核心库，AI 对战无需经过网络
- **免费额度慷慨**：Workers 10 万请求/天，D1 5M 读/天，KV 10 万读/天
- **成本极低**：个人项目基本免费，中等规模月费极低
- **GitHub 一键登录**：OAuth 回调由 Workers 处理，无需独立认证服务

### 4.2 棋盘模块 (src/board.rs)

```rust
use serde::{Deserialize, Serialize};

pub const BOARD_SIZE: usize = 15;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub enum Piece {
    Empty,
    Black,
    White,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Board {
    pub grid: [[Piece; BOARD_SIZE]; BOARD_SIZE],
    pub current_player: Piece,
    pub move_history: Vec<(usize, usize)>,
}

impl Board {
    pub fn new() -> Self {
        Board {
            grid: [[Piece::Empty; BOARD_SIZE]; BOARD_SIZE],
            current_player: Piece::Black,
            move_history: Vec::new(),
        }
    }

    pub fn place_piece(&mut self, row: usize, col: usize) -> Result<(), String> {
        if row >= BOARD_SIZE || col >= BOARD_SIZE {
            return Err("坐标超出范围".into());
        }
        if self.grid[row][col] != Piece::Empty {
            return Err("该位置已有棋子".into());
        }
        self.grid[row][col] = self.current_player.clone();
        self.move_history.push((row, col));
        self.current_player = match self.current_player {
            Piece::Black => Piece::White,
            Piece::White => Piece::Black,
            Piece::Empty => Piece::Empty,
        };
        Ok(())
    }

    pub fn undo(&mut self) -> Option<(usize, usize)> {
        if let Some((row, col)) = self.move_history.pop() {
            self.grid[row][col] = Piece::Empty;
            self.current_player = match self.current_player {
                Piece::Black => Piece::White,
                Piece::White => Piece::Black,
                Piece::Empty => Piece::Empty,
            };
            Some((row, col))
        } else {
            None
        }
    }

    /// 检查最后一步是否形成五连
    pub fn check_win(&self) -> Option<(Piece, Vec<(usize, usize)>)> {
        if let Some(&(row, col)) = self.move_history.last() {
            let piece = &self.grid[row][col];
            if *piece == Piece::Empty { return None; }

            let directions = [(0,1), (1,0), (1,1), (1,-1)];
            for (dr, dc) in directions {
                let mut line = vec![(row, col)];
                // 正方向
                for i in 1..5 {
                    let nr = row as i32 + dr as i32 * i as i32;
                    let nc = col as i32 + dc as i32 * i as i32;
                    if nr < 0 || nr >= BOARD_SIZE as i32 || nc < 0 || nc >= BOARD_SIZE as i32 { break; }
                    if self.grid[nr as usize][nc as usize] != *piece { break; }
                    line.push((nr as usize, nc as usize));
                }
                // 反方向
                for i in 1..5 {
                    let nr = row as i32 - dr as i32 * i as i32;
                    let nc = col as i32 - dc as i32 * i as i32;
                    if nr < 0 || nr >= BOARD_SIZE as i32 || nc < 0 || nc >= BOARD_SIZE as i32 { break; }
                    if self.grid[nr as usize][nc as usize] != *piece { break; }
                    line.push((nr as usize, nc as usize));
                }
                if line.len() >= 5 {
                    return Some((piece.clone(), line));
                }
            }
        }
        None
    }
}
```

### 4.3 LLM AI 模块 (src/ai/mod.rs)

```rust
use async_trait::async_trait;
use serde::{Deserialize, Serialize};
use crate::board::Board;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LLMResponse {
    pub row: usize,
    pub col: usize,
    pub message: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum LLMProvider {
    OpenAI { api_key: String, model: String, base_url: Option<String> },
    Anthropic { api_key: String, model: String },
    Ollama { base_url: String, model: String },
}

#[async_trait]
pub trait LLMService: Send + Sync {
    async fn get_move(&self, board: &Board, player: &str) -> Result<LLMResponse, String>;
}

pub struct OpenAIProvider {
    client: async_openai::Client,
    model: String,
}

impl OpenAIProvider {
    pub fn new(api_key: &str, model: &str, base_url: Option<&str>) -> Self {
        let mut config = async_openai::Config::new().with_api_key(api_key);
        if let Some(url) = base_url {
            config = config.with_api_base(url);
        }
        let client = async_openai::Client::with_config(config);
        OpenAIProvider { client, model: model.to_string() }
    }
}

#[async_trait]
impl LLMService for OpenAIProvider {
    async fn get_move(&self, board: &Board, player: &str) -> Result<LLMResponse, String> {
        let board_str = serialize_board(board);
        let system_prompt = format!(r#"你是一个五子棋 AI 对手。棋盘如下（0=空，1=黑，2=白）：
{board_str}
你是{player}方。请返回 JSON：{{"row": 0-14, "col": 0-14, "message": "可选评语"}}"#);

        let request = async_openai::types::CreateChatCompletionRequestArgs::default()
            .model(&self.model)
            .response_format(async_openai::types::ChatCompletionResponseFormat::Json { schema: None })
            .user(&system_prompt)
            .max_tokens(200u32)
            .build()
            .map_err(|e| e.to_string())?;

        let response = self.client.chat().create(request).await.map_err(|e| e.to_string())?;
        let content = response.choices[0].message.content.as_ref()
            .ok_or("LLM 返回空内容")?;
        serde_json::from_str(content).map_err(|e| format!("JSON 解析失败: {}", e))
    }
}

fn serialize_board(board: &Board) -> String {
    board.grid.iter()
        .map(|row| row.iter().map(|p| match p {
            crate::board::Piece::Empty => "0",
            crate::board::Piece::Black => "1",
            crate::board::Piece::White => "2",
        }).collect::<Vec<_>>().join(" "))
        .collect::<Vec<_>>()
        .join("\n")
}
```

### 5.2 Tauri Rust 后端 (src-tauri/src/main.rs)

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

use gomoku_core::{Board, Piece, ai::{LLMService, LLMProvider, OpenAIProvider}};
use tauri::State;
use std::sync::Mutex;

struct AppState {
    board: Mutex<Board>,
}

#[tauri::command]
fn place_piece(state: State<AppState>, row: usize, col: usize) -> Result<bool, String> {
    let mut board = state.board.lock().map_err(|e| e.to_string())?;
    board.place_piece(row, col).map(|_| true)
}

#[tauri::command]
fn undo_piece(state: State<AppState>) -> Result<Option<(usize, usize)>, String> {
    let mut board = state.board.lock().map_err(|e| e.to_string())?;
    Ok(board.undo())
}

#[tauri::command]
fn check_win(state: State<AppState>) -> Result<Option<String>, String> {
    let board = state.board.lock().map_err(|e| e.to_string())?;
    Ok(board.check_win().map(|(piece, _)| match piece {
        Piece::Black => "black".to_string(),
        Piece::White => "white".to_string(),
        Piece::Empty => "empty".to_string(),
    }))
}

#[tauri::command]
async fn ai_move(state: State<AppState>, provider_config: serde_json::Value) -> Result<serde_json::Value, String> {
    let board = state.board.lock().map_err(|e| e.to_string())?;
    let provider: LLMProvider = serde_json::from_value(provider_config).map_err(|e| e.to_string())?;

    // 根据 provider 类型创建对应的 LLM 服务
    let response = match provider {
        LLMProvider::OpenAI { api_key, model, base_url } => {
            let service = OpenAIProvider::new(&api_key, &model, base_url.as_deref());
            service.get_move(&board, "white").await?
        }
        // Anthropic 和 Ollama 类似实现...
        _ => return Err("暂不支持的 provider".into()),
    };

    Ok(serde_json::to_value(response).map_err(|e| e.to_string())?)
}

fn main() {
    tauri::Builder::default()
        .manage(AppState {
            board: Mutex::new(Board::new()),
        })
        .invoke_handler(tauri::generate_handler![place_piece, undo_piece, check_win, ai_move])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

use worker::*;

#[event(fetch)]
async fn main(req: Request, env: Env, _ctx: Context) -> Result<Response> {
    let router = Router::new();

    // GitHub OAuth
    router
        .get("/api/auth/github", |req, ctx| async move {
            let oauth_url = format!(
                "https://github.com/login/oauth/authorize?client_id={}&redirect_uri={}&scope=read:user,user:email",
                ctx.env.var("GITHUB_CLIENT_ID")?.to_string(),
                ctx.env.var("GITHUB_REDIRECT_URI")?.to_string()
            );
            Response::redirect(Url::parse(&oauth_url).unwrap())
        })
        .get("/api/auth/github/callback", |req, ctx| async move {
            // OAuth 回调处理...
            Response::ok("OK")
        })
        // AI 落子
        .post_async("/api/ai/move", |mut req, ctx| async move {
            let body: serde_json::Value = req.json().await?;
            // 调用 gomoku-core 的 LLM 服务...
            Response::from_json(&serde_json::json!({"row": 7, "col": 7}))
        })
        // D1 数据库操作
        .get_async("/api/users/me", |_req, ctx| async move {
            let d1 = ctx.env.d1("DB")?;
            let result = d1.prepare("SELECT * FROM users WHERE id = ?1")
                .bind(&[1])?.first::<serde_json::Value>().await?;
            Response::from_json(&result)
        })
        .run(req, env).await
}

import { invoke } from '@tauri-apps/api/core';

export async function placePiece(row: number, col: number) {
  if (isTauri) {

    return invoke<LLMResponse>('ai_move', { providerConfig: config });
  } else {
    // Web 端通过 Workers 代理调用 LLM
    return axios.post('/api/ai/move', config);
  }

```sql
-- schema.sql（D1 使用 SQLite 语法）

CREATE TABLE IF NOT EXISTS users (
  id TEXT PRIMARY KEY DEFAULT (lower(hex(randomblob(16)))),
  github_id INTEGER UNIQUE,
  username TEXT NOT NULL,
  avatar TEXT,
  rating INTEGER DEFAULT 1200,
  wins INTEGER DEFAULT 0,

  draws INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS game_records (
  id TEXT PRIMARY KEY DEFAULT (lower(hex(randomblob(16)))),
  black_player_id TEXT NOT NULL REFERENCES users(id),
  white_player_id TEXT NOT NULL REFERENCES users(id),
  winner_id TEXT REFERENCES users(id),
  game_mode TEXT NOT NULL,
  moves TEXT NOT NULL,  -- JSON 字符串
  duration INTEGER,
  created_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS rooms (
  id TEXT PRIMARY KEY DEFAULT (lower(hex(randomblob(16)))),
  name TEXT NOT NULL,
  host_id TEXT NOT NULL REFERENCES users(id),
  status TEXT DEFAULT 'waiting',
  game_mode TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now'))
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_users_github_id ON users(github_id);
CREATE INDEX IF NOT EXISTS idx_game_records_black ON game_records(black_player_id);
CREATE INDEX IF NOT EXISTS idx_game_records_white ON game_records(white_player_id);
```

## 十四、Cloudflare 成本估算

| 服务 | 免费额度 | 付费价格 | 说明 |
|------|---------|---------|------|
| Workers | 10 万请求/天 | $5/月（1000万请求） | 个人项目免费足够 |
| Pages | 500 次构建/月 | $5/月（无限构建） | 静态站点托管 |
| D1 | 5M 行读/天，100K 行写/天 | $0.75/百万读 | SQLite 数据库 |
| KV | 10 万读/天，1K 写/天 | $0.50/百万读 | 键值缓存 |
| R2 | 10GB 存储，100万 A 类操作/月 | $0.015/GB/月 | 对象存储 |
| Durable Objects | 无免费额度 | $0.15/百万请求 + $0.25/GB内存/秒 | WebSocket |

> 个人项目估算：Workers + Pages + D1 + KV + R2 基本在免费额度内。Durable Objects（在线联机）需少量付费，预估月费 $1-5。
